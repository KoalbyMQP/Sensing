# Chess Vision Module

Computer vision for chess applications using OAK-D camera.

## Structure
```
Chess/
├── src/           # Chess vision algorithms and core code
├── demos/         # Demonstration scripts and examples
├── docs/          # Documentation and technical specifications
├── data/          # Training data, images, and datasets
├── models/        # Machine learning models for piece recognition
└── README.md      # This file
```

## Description
This module provides computer vision capabilities specifically for chess applications. It enables chess board detection, piece identification, move validation, and game state tracking using the OAK-D camera. The module is designed with a modular architecture supporting various chess-related computer vision tasks.
