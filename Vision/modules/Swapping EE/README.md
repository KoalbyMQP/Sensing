# Swapping EE Vision Module

Computer vision for end effector swapping applications using OAK-D camera.

## Structure
```
Swapping EE/
├── src/           # End effector swapping algorithms and core code
├── demos/         # Demonstration scripts and examples
├── docs/          # Documentation and technical specifications
├── data/          # Training data, images, and datasets
├── models/        # Machine learning models for end effector recognition
└── README.md      # This file
```

## Description
This module provides computer vision capabilities specifically for end effector swapping applications. It enables end effector detection, identification, positioning validation, and swap sequence tracking using the OAK-D camera. The module is designed with a modular architecture supporting various end effector-related computer vision tasks for robotic manipulation.
