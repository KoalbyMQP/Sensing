# Temperature Vision Module

Computer vision for temperature measurement applications using OAK-D camera.

## Structure
```
Temperature/
├── src/           # Temperature measurement algorithms and core code
├── demos/         # Demonstration scripts and examples
├── docs/          # Documentation and technical specifications
├── data/          # Training data, images, and datasets
├── models/        # Machine learning models for person detection and targeting
└── README.md      # This file
```

## Description
This module provides computer vision capabilities specifically for temperature measurement applications. It enables person detection, facial recognition for targeting, distance measurement, and temperature probe positioning using the OAK-D camera. The module is designed with a modular architecture supporting various temperature measurement-related computer vision tasks for medical or health monitoring applications.
